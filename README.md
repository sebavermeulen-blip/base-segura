# Base Segura (demo)

App web personal (PWA) para la ansiedad y los problemas emocionales del día a día: check-in guiado que recomienda herramientas (TCC, terapia de esquemas, DBT, ACT, compasión, mindfulness), "Calma ahora", sesión diaria de 21 días, diario, patrones ("lo que te funciona"), esquemas, registro de cannabis, plan de seguridad y un acompañante opcional con IA (Claude).

- Sin servidor, sin cuentas, sin rastreadores: los datos se guardan solo en el dispositivo, con exportación cifrada (AES-GCM).
- La IA es opcional: usa la clave de API de la propia persona y solo envía la charla y un resumen de contexto que ella elige.
- No sustituye la psicoterapia.
