# Base Segura (demo)

App web personal (PWA) para practicar a diario herramientas de terapia de esquemas: sesión matutina, pausa guiada para discusiones, diario de modos, patrones, registro de cannabis y plan de seguridad.

- Sin servidor, sin cuentas, sin rastreadores: los datos se guardan solo en el dispositivo (localStorage), con exportación cifrada (AES-GCM).
- No sustituye la psicoterapia.
